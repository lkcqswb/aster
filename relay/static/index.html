How the loop works

Task + files→Model⇄Tools→Checks

Each turn records tool arguments and results. After tool execution, Aster saves the conversation and workspace as a checkpoint. When the model finishes, Aster checks its files against your original criteria.

MiniMax receives task instructions and tool results. Credentials never enter the model conversation or browser. This version supports text files and arithmetic; it does not execute shell commands.

Turn, tool, time, and output-token limits bound each run. These are not currency spending caps. Truncated responses and provider errors stop the run without automatic retries.
